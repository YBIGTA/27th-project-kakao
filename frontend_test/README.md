# 카카오 선물 추천 프론트엔드

카카오톡 대화 분석을 통한 맞춤형 선물 추천 서비스의 프론트엔드입니다.

## 기능

- 카카오톡 대화 파일 업로드 (TXT 형식)
- 사용자 정보 입력 (나이, 관계, 예산 범위)
- 실시간 추천 결과 표시
- 반응형 디자인

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm start
```

## 사용법

1. 카카오톡에서 대화 내보내기 (TXT 파일)
2. 웹페이지에서 파일 업로드
3. 나이, 관계, 예산 범위 입력
4. "선물 추천 받기" 버튼 클릭
5. 분석 결과 확인

## 기술 스택

- React 18
- TypeScript
- Axios (HTTP 클라이언트)
- CSS3 (모던 스타일링)

## API 엔드포인트

- `POST /api/recommend`: 선물 추천 요청
  - 입력: `file`, `age`, `relation`, `budget_min`, `budget_max`
  - 출력: 추천 상품 목록, 분석 근거 문장
